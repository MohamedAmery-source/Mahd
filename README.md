# موقع مهد العامري — صيانة الأجهزة المنزلية

موقع عربي RTL متجاوب، مصمم خصيصاً لفني صيانة الأجهزة الكهربائية المنزلية مهد عبدالعظيم منصور عبده العامري. يتضمن واجهة تعريفية، الخدمات، أنواع الأجهزة، نبذة مهنية، خطوات العمل، وأزرار اتصال مباشرة.

## التشغيل باستخدام Docker Compose

1. ارفع المجلد إلى الخادم الذي يحتوي على Docker وDocker Compose.
2. تأكد من وجود شبكة Traefik الخارجية باسم `traefik`، وأن Traefik يستخدم مدخل `websecure` ومُصدر شهادات `letsencrypt`.
3. انسخ `.env.example` إلى `.env` وعدّل `DOMAIN` إلى النطاق الذي يشير إلى عنوان الخادم.
4. شغّل:

```bash
docker compose up -d --build
```

## ملاحظات
- لا يحتاج الموقع إلى قاعدة بيانات أو خدمة API؛ إنه موقع تعريفي ثابت وخفيف.
- إعداد النطاق الافتراضي هو `mahd.simoiot.info` ويمكن تغييره في `.env`.
- زر الاتصال يستخدم الرقم `736786536` كما زُوّد. عند الحاجة إلى صيغة دولية، عدّل الرقم في روابط `tel:` داخل `frontend/index.html`.
- الخطوط تُحمّل من Google Fonts عند توفر اتصال الإنترنت؛ توجد خطوط بديلة محلية في سلسلة الخطوط لضمان بقاء الصفحة قابلة للقراءة.
